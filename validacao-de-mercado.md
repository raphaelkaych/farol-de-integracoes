# O que o portfólio precisa demonstrar

Consulta em 5 de novembro de 2026. A amostra reúne três vagas brasileiras de entrada em desenvolvimento e análise de sistemas, uma de nível pleno como referência de evolução e dois guias de plataformas de recrutamento. A leitura é qualitativa.

| Fonte | O que aparece na descrição |
| --- | --- |
| [Itaú Unibanco · Engenharia de TI Júnior, backend de dados](https://vemproitau.gupy.io/jobs/12512385) | Pede Python, SQL, AWS e Git/GitHub. Entre as atividades estão documentação técnica, CI/CD com GitHub Actions, resiliência e observabilidade. Experiência com APIs aparece como diferencial. |
| [Confitec · Desenvolvimento Fullstack Backend, trainee](https://confitec.gupy.io/jobs/12741460) | Considera conhecimentos adquiridos em projetos acadêmicos ou profissionais. Lista APIs REST, SQL básico e controle de versão com Git. O processo inclui um teste e uma entrevista técnica. |
| [Lanlink · Análise de Sistemas Júnior](https://vempralanlink.gupy.io/jobs/12668036?jobBoardSource=gupy_public_page) | O trabalho inclui levantar e documentar requisitos, consultar e validar dados com SQL, desenvolver e consumir APIs, investigar falhas e apoiar testes e homologação. |
| [Lumini IT · Desenvolvimento Full Stack II, pleno](https://luminiitsolutions.gupy.io/jobs/11585160) | Pede experiência com Python, APIs REST, banco relacional e testes. Cita FastAPI e PostgreSQL entre opções e indica Docker e GitHub Actions como diferenciais. |

As três vagas de entrada mencionam SQL e APIs, com pesos diferentes. Itaú e Confitec também citam Git. Para a parte técnica do portfólio, a aplicação é mostrar essas habilidades em um fluxo completo: receber e validar um evento, registrar o que aconteceu e verificar como o sistema reage a uma falha. Um caso reproduzível liga o código à necessidade operacional que ele resolve.

Na apresentação, a Empregare recomenda contextualizar o problema, explicar decisões e limites e cuidar da legibilidade do README e do histórico. O Vaga Já, da Gupy, orienta incluir links para o portfólio e o GitHub, com uma descrição do que foi feito, da tecnologia e do resultado. [Empregare · Portfólio, GitHub e testes técnicos](https://nectar.empregare.com/portfolio-github-e-testes-tecnicos-o-que-realmente-pesa-hoje-nas-contratacoes-em-tecnologia/), [Vaga Já · Currículo de desenvolvedor de software](https://candidato-ja.gupy.io/blog/curriculo-desenvolvedor-ti)

Para este portfólio, a escolha é destacar uma demonstração acessível sem cadastro e um repositório que permita conferir a implementação. O README pode abrir com o problema e a ação que vale testar, seguido de como rodar o sistema, como reproduzir a falha e quais decisões explicam o comportamento observado.
